## 介面定義
每個確定需要的介面以 API-001 起編號，補齊以下內容：
- 用途、HTTP 方法與路徑。
- 認證方式與權限要求。
- 請求欄位、型別、必填、限制及範例。
- 回應欄位、型別、可空性及範例。
- 狀態碼、錯誤碼與失敗情境。
- 分頁、排序、冪等性與相容性要求（依需求填寫）。

目前沒有可供串接的確定介面。
